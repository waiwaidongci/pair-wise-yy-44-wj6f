# 巡演舞台调度与走位编排工作台

面向剧院巡演团队的舞台执行工作台，覆盖演员与道具调度、舞台走位、执行提示、留言协同、版本回退、基线锁定和演出文档打印。

## 技术栈

Vue 3 + Element Plus + Pinia + Vue Router + TanStack Query + Axios + MSW + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62044`。

## 核心工作流

- 在舞台平面图中选择走位，编辑入场点、退场点、路线节点和触发时机。
- 在同一脚本时间线中维护灯光、音响、道具与执行提示。
- 添加部门留言、标记问题并生成修改版本；撤销、重做和离线草稿会自动保存。
- 锁定演出基线，并从打印中心输出走位表和执行清单。

## 断网换场双端合并

巡演换场断网时，舞台监督与前场导演可在两台终端同时保存同一提示。进入「断网合并」台可一键模拟该场景：

1. 断网瞬间拍下共同基线，双端各自的字段修改、路线节点改动、追加节点与留言进入本机队列。
2. 网络恢复后**按提示编号**做三方合并（基线 + 舞台监督端 + 前场导演端）：
   - 只有一端改过的字段直接并入；
   - 双方都改过且不一致的字段（触发时间、入场点、退场点、路线节点坐标）并列保留为**待核差异**：路线节点主坐标与另一端坐标同时显示在平面图上。
3. 待核差异命中**互锁**提示（触发时间 / 出入场点 / 路线坐标）时，**演出基线停住**、清单编辑停用，人工逐项裁决后才恢复。
4. 合并失败时本机队列原样保留可重试；重试与合并均按内容去重，**留言与路线节点不重复追加**。
5. 基线锁定后的改动自动另开**修订稿**；打印中心在锁定期间始终输出锁定时的**旧版清单**，CSV 与打印件一致。
