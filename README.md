# 巡演舞台调度与走位编排工作台

面向剧院巡演团队的舞台执行工作台，覆盖演员与道具调度、舞台走位、执行提示、留言协同、版本回退、基线锁定和演出文档打印。

## 技术栈

Vue 3 + Element Plus + Pinia + Vue Router + TanStack Query + Axios + MSW + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62044`。

## 核心工作流

- 在舞台平面图中选择走位，编辑入场点、退场点、路线节点和触发时机。
- 在同一脚本时间线中维护灯光、音响、道具与执行提示。
- 添加部门留言、标记问题并生成修改版本；撤销、重做和离线草稿会自动保存。
- 锁定演出基线，并从打印中心输出走位表和执行清单。

## 离线协同合并

巡演换场时，舞台监督和前场导演会在断网终端同时保存同一提示的入场点、路线和触发时间。网络恢复后按提示编号合并两边操作：

- **按提示编号合并**：联网后将两边的离线操作按 `cueId` 对齐，逐字段并入基线。
- **一边改过直接并入**：只有一方修改的字段（入场点、退场点、触发时间等）直接采用。
- **双方都改过的路线节点并列成待核差异**：同一节点两边都改到不同坐标时，保留两种坐标并列（图上以橙色虚线圆点标记对方坐标），列入「待核差异」等待取舍。
- **互锁差异令基线停住**：当差异落在互锁提示（如 C-04 灯光爆闪与机械互锁）的路线或触发时间上时，演出基线先停住，打印中心保留旧版清单，直到差异处理完毕。
- **合并失败队列留着重试**：合并失败时本机队列保留操作，可在「离线协同」页重试；留言和路线按客户端编号去重，重试不重复追加。
- **基线锁定后另开修订稿**：基线锁定后的修改进入修订稿（草稿分支），不影响已锁定的基线。

在左侧边栏切换终端角色（舞台监督 / 前场导演），点击「模拟离线」即可在断网终端各自编辑；恢复网络时自动合并。合并状态与待核差异可在「离线协同」页查看和处理。
